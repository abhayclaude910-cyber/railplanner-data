# railplanner-data

Offline train timetable packs for the Rail Planner app, built from **open GTFS data**.

- `pipeline/`: Python scripts (standard library only)
  - `download.py`: fetches the feeds listed in `feeds.json` into `raw/`
  - `build.py`: makes one SQLite pack per country + a station search index + `manifest.json` in `out/`
  - `query.py`: test tool, station search and route search over the built packs
- `FORMAT.md`: the pack format the app reads.
- Packs are published as **GitHub Release assets**, not committed. `raw/`, `work/` and `out/` are git-ignored.

```
python pipeline/download.py
python pipeline/build.py
python pipeline/query.py route "Muenchen Hbf" "Amsterdam Centraal" 2026-11-20 08:00
```

**Not included yet** (of the 33 Interrail countries):
- Need a free account or key (keys go into GitHub Actions secrets, never the app): Hungary (MÁV registration), Great Britain (National Rail Data Portal; CIF format needs a converter). Austria's non-ÖBB operators need a Mobilitätsverbünde account.
- Current file not found: Croatia (the official HŽPP link still serves the 2024-25 timetable).
- No usable open timetable: Italy (only a non-commercial proxy), Bosnia and Herzegovina (no rail feed).
- Known gaps: Serbia's file lists Petrovaradin but not Novi Sad on Belgrade-Subotica trains; international trains split between two sources (e.g. EC Berlin-Prague: German data ends at Děčín) show as a change at the border.
- Outside Europe (USA, Canada, Australia, Taiwan): need time-zone support and licence checks.

The packs are changed (filtered to trains, ferries and coaches; stations merged across feeds) and keep each source's licence. Every pack carries these credits in its `meta.credits`.
